# How to See Dashboard Updates

The dashboard has been updated with Amazon Bedrock branding, but your browser is showing cached content.

## Quick Fix - Hard Refresh

### On Chrome/Edge (Windows/Linux):
Press: `Ctrl + Shift + R` or `Ctrl + F5`

### On Chrome/Edge (Mac):
Press: `Cmd + Shift + R`

### On Firefox (Windows/Linux):
Press: `Ctrl + Shift + R` or `Ctrl + F5`

### On Firefox (Mac):
Press: `Cmd + Shift + R`

### On Safari (Mac):
Press: `Cmd + Option + R`

## Alternative Method - Clear Cache Manually

1. Open Developer Tools (F12)
2. Right-click the refresh button
3. Select "Empty Cache and Hard Reload"

If hard refresh doesn't work:
1. Clear all browser cache (Settings > Privacy > Clear browsing data)
2. Close and reopen the browser
3. Visit the dashboard in an incognito/private window
